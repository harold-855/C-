# sintaxis
 
 Es el conjunto de reglas que indican cómo debemos escribir correctamente un código para que el lenguaje de programación pueda entenderlo.

 En C#, por ejemplo:

```csharp
int edad = 27;
 ```

Cada elemento sigue las reglas de sintaxis de C#:
```
int → tipo de dato.
edad → nombre de la variable.
= → operador de asignación.
27 → valor.
; → indica el final de la instrucción.
```

 ## Comentarios en C# 
Los comentarios, son líneas de texto que el compilador ignora. Según .NET Documentation (2022) estos se utilizan para añadir notas o explicaciones en el código y hacen que el código sea más fácil de entender, tanto para ti como para otros programadores. C# soporta dos tipos de comentarios:  

### Comentarios de una sola línea: 
Se utilizan para agregar una breve descripción o comentario en una sola línea. Comienzan con //

```
//Este es un comentario de una sola linea
```

### Comentarios de múltiples líneas:
Se usan para comentarios más largos o bloques de texto que abarcan varias líneas. Comienzan con /* y terminan con */.

```
/* Este es un comentario 
   de múltiples líneas. */ 
```
