# Glosario

## lenguaje compilado

Un lenguaje compilado es un lenguaje de programación cuyo codigo fuente escrito por humanos se traduce por completo a lenguaje maquina (codigo binario) antes de que el programa se pueda ejecutar. Esta traducción previa la realiza un programa especializado llamado compilador 

El resultado de este proceso es un archivo ejecutable independiente (Como un archivo exe en windows ) que la computadora entiende y procesa a maxima velocidad,sin la necesidad de tener el codigo original ni el compilador instalador.

## Ide

Entorno de desarrollo integrado es un programa que reune en un solo lugar las herramientas necesarias para desarrollsr software.

## SDK

Software development kit es un cojunto de herramientas y recursos de desarrollo que permiten crear,compilar,probar y distribuir aplicasiones para una plataforma o tecnologia especifica.
