# ¿Qué es el Polimorfismo?

El polimorfismo, es la capacidad de un objeto de tomar muchas formas. En términos simples, significa que un método o función puede comportarse de diferentes maneras según el objeto que lo invoque. Esto, se consigue mediante la herencia y la sobreescritura de métodos. (Principios de La POO, 2022)

**Tipos de Polimorfismo**

Ahora vamos a ver cómo usar el polimorfismo en C#:

* **1. Polimorfismo en tiempo de compilación**
* **2. Polimorfismo en tiempo de ejecución**

# Polimorfismo en tiempo de compilación (Sobrecarga de métodos)

Cuando una clase tiene más de un método con el mismo nombre, pero diferentes parámetros. C# selecciona el método adecuado según los argumentos que le pases. Por ejemplo:

```csharp
public class Calculadora
{
    public int Sumar(int a, int b)
    {
        return a + b;
    }

    public double Sumar(double a, double b)
    {
        return a + b;
    }
}

```

*Coloca el cursor sobre el código para obtener una descripción de la función de cada bloque.*

Cuando nosotros queremos usar los métodos, es C# quien decide cuál de los 2 métodos va a utilizar de acuerdo con los argumentos que le pasemos al método.

---

```csharp
var Calculadora = new Calculadora();

Calculadora.Sumar(2, 2);

```

Para cerrar este ejemplo recuerda siempre que el polimorfismo nos permite utilizar un mismo método para realizar distintas acciones, evitando la necesidad de crear múltiples métodos con nombres diferentes para realizar la misma lógica. Esto, facilita el mantenimiento y la comprensión del código, ya que un único método puede comportarse de manera distinta según el contexto o los objetos con los que esté trabajando.

# Polimorfismo en tiempo de ejecución (Sobreescritura de métodos)

Se da cuando una clase derivada (hija) modifica el comportamiento de un método heredado de la clase base (padre). Para lograr esto se utiliza la palabra clave virtual en el método de la clase padre y override en la clase hija.

* **Clase padre**
* **Clase hija**

# Clase padre

```csharp
public class Animal
{
    public virtual void HacerSonido()
    {
        Console.WriteLine("El animal hace un sonido");
    }
}

```

# Clase hija

```csharp
public class Perro : Animal
{
    public override void HacerSonido()
    {
        Console.WriteLine("El perro ladra");
    }
}

```

**Nota:** *Cuando una clase hija sobreescribe un método de la clase padre, el método original en la clase padre no se borra ni se modifica. La clase hija, solo redefine cómo funciona ese método para ella misma.*

También existen algunos casos, donde no queremos reemplazar el método de la clase padre; si no, usarlo y luego añadir nuestro propio comportamiento, para lograr este comportamiento, usamos la palabra reservada **base**

* **Clase padre**
* **Clase padre**

# Clase padre

```csharp
public class Animal
{
    public virtual void HacerSonido()
    {
        Console.WriteLine("El animal hace un sonido");
        Console.WriteLine("cuando quiere pelear");
    }
}

```

# Clase padre

```csharp
public class Leon : Animal
{
    public override void HacerSonido()
    {
        base.HacerSonido();
        Console.WriteLine("Pero el Leon ruje como el rey de la sabana");
    }
}

```
