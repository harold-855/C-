# Programación orientada a objetos

La Programación Orientada a Objetos (POO) es un **paradigma** de programación que se basa en organizar el código en objetos. Un objeto no es más que una representación de algo que existe en el mundo real, con características (propiedades) y acciones (métodos). Este enfoque ayuda a estructurar el código de manera más clara, permitiendo que sea fácil de mantener y reutilizar. (Aguilar, 1996)

La orientación a objetos se ha convertido en un enfoque muy popular para el desarrollo de software, ya que ofrece varias ventajas como la modularidad, la reutilización de código y una mejor escalabilidad.

---

### ¿Por qué es útil la POO?

Imagina que estás programando un videojuego. Tienes personajes, enemigos, armas, y cada uno de estos elementos tiene características diferentes. Sin la POO, todo esto podría volverse un caos. Con la POO, puedes organizar todos estos elementos en clases, que son como moldes para crear los objetos. Cada clase define los atributos y métodos de los objetos que crearás.

La idea es que todo en tu código esté organizado como si estuvieras modelando el mundo real, lo que hace que programar sea más intuitivo y fácil de manejar.

Por ejemplo, en tu videojuego tienes personajes por lo tanto deberás crear una clase llamada **Personaje**, dicha clase podría tener propiedades como **Nombre**, **Vida**, y **Nivel**, y métodos como **Atacar()** y **Curarse()**. Luego, puedes crear tantos personajes como quieras a partir de esa clase.
